## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Iqbal-Syukron/Portofolio-Web.git
   ```

2. **Navigate into the project directory**
   ```bash
   cd Portofolio-Web
   ```

3. **Install Dependencies**
   ```bash
   composer install
   npm install
   ```

4. **Environment Setup**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

5. **Run Application**
   ```bash
   php artisan serve
   ```
